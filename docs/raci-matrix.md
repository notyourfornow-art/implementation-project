# Матрица ответственности RACI

| Действие | Deploy manager | Support manager | Разработчик | Заказчик |
|----------|---------------|-----------------|-------------|----------|
| План deployment | A/R | C | C | I |
| Пакет и миграции | A | I | R | I |
| Smoke-тест | A | C | R | I |
| Обучение поддержки | C | A/R | C | I |
| Решение о запуске | R | C | C | A |
| Инциденты после запуска | I | A/R | R (L3) | I |

**R** — выполняет, **A** — отвечает за результат, **C** — консультирует, **I** — информируется.
