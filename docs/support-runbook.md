# Runbook сопровождения (L1/L2)

## Приём обращений
- Канал: helpdesk@example.edu, тел. 200
- Регистрация в системе заявок, категория: «Информационная система»
- Приоритет: P1 — сервис недоступен всем; P2 — недоступна функция; P3 — локальная проблема; P4 — консультация

## Типовые диагностики
| Симптом | Проверка | Действие L1 |
|---------|----------|-------------|
| Не открывается сайт | `curl -I http://helpdesk.local` | Перезапуск контейнера frontend, эскалация L2 |
| Ошибка при создании заявки | Логи backend | Собрать текст ошибки, эскалация L2 |
| Не приходит уведомление | Статус notifications worker | Проверить настройки SMTP, эскалация L2 |

## Эскалация
- L2: deploy@example.edu (инфраструктура, конфигурация)
- L3: dev@example.edu (дефекты кода)
- Вендор: PostgreSQL support (критические проблемы БД)

## SLA
- Реакция P1: 15 минут, восстановление: 2 часа
- Реакция P2: 1 час, восстановление: 8 часов
- Доступность: 99,5% в месяц

## Известные ограничения v1.2.0
- Уведомления в Telegram работают только для пользователей с заполненным `@username`
- Максимальный размер вложения заявки — 10 МБ
